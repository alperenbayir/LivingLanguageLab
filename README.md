# Living Language Lab

A VR game for learning German vocabulary, built in Unity for the Meta Quest 3.
Fachprojekt in Human-AI/Computer Interaction at TU Dortmund.

## What it does

You explore a virtual kitchen and scan objects with the VR controller. Whatever you scan appears on
the tablet you carry: the German word with its article, the translation, and audio you can play to
hear it pronounced. You can then try saying the word yourself. A counter tracks how many words you
have found, and example sentences are generated so a word is shown in use rather than on its own.

Once enough of the kitchen has been explored, challenges unlock:

- **Find-object quiz** — a word is given, you find and grab the matching object
- **Article quiz** — sort items into der / die / das baskets
- **Food combination game**
- **Preposition game** — place objects to practise positional prepositions

## Built with

- Unity 6 (6000.2.14f1)
- XR Interaction Toolkit, OpenXR, Oculus XR, XR Hands — tested on Meta Quest 3
- Meta XR Voice SDK (Wit.ai) for speech input
- Android text-to-speech for pronunciation playback
- Example sentences generated by a self-hosted Ollama instance running `gemma2:2b`, with history
  tracking so sentences do not repeat
- Vocabulary and audio from `Assets/_Project/Resources/vocabulary.json` plus mp3 files
- Food and kitchen models from Kenney's free asset packs

## Running it

Open the project in Unity 6 and build for Android with a Meta Quest as the target device.
It needs a headset — there is no desktop mode.

Sentence generation expects an Ollama server on the local network. The address is hardcoded in
`Assets/_Project/Scripts/SentenceGenerator.cs` and has to be changed to your own machine.
